# SoS Story Forge

AI-assisted story generation system for Sisters of Summerville.

## Features

- GitHub Pages compatible
- stories.json archive
- GitHub Actions story generation
- Tidbit research databases
- Future-ready for LangChain + FAISS integration

## Setup

1. Upload all files to your GitHub repo
2. Enable GitHub Pages
3. Enable GitHub Actions write permissions
4. Run workflow manually from Actions tab
